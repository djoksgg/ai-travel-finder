AI TRAVEL FINDER — staticki promotivni sajt

Sadrzaj: index.html

Da vidis sajt: dvoklik na index.html (fotografije zahtevaju internet).

Za besplatan javni URL putem GitHub Pages:
1. Napravi GitHub nalog ako ga nemas.
2. Kreiraj PUBLIC repository po imenu ai-travel-finder.
3. Dodaj index.html u glavni (root) folder repozitorijuma i Commit.
4. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. Kada objava uspe, adresa je https://TVOJ_USERNAME.github.io/ai-travel-finder/
6. Otvori tu adresu u privatnom/incognito prozoru da proveris da je javna, pa je unesi u CJ.

Nemoj slati .env, API kljuceve, Python kod projekta, niti .venv na GitHub.
